# Events Conducted photographs

The JPEGs in these event folders were extracted from the supplied IIC Activity Report and compressed for web delivery. They are mapped in data/events-conducted.js:

- altera-fpga/ — Altera FPGA workshop
- cadence-rtl-gds/ — Cadence RTL-to-GDS workshop
- frontend-cadence/ — Cadence front-end design training
- synopsys-workshop/ — Synopsys RTL-to-GDS workshop
- tecktors-kalam26/ — TECKTORS / CHIP CREATORS workshop
- backend-cadence/ — Cadence back-end design training
- chip-design/ — Cadence tool-chain training
- veltraxx26/ — VELTRAXX ’26 hackathon

Only event photographs are published here. Attendance sheets from the report are excluded. For future photos, add optimized .jpg, .webp, or .avif files to the appropriate event folder, then add each relative path and descriptive alt text to that event's photos array.
